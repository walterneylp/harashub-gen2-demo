# HarasHub Gen2 — demonstração visual

Protótipo estático, responsivo e 100% demonstrativo do **HarasHub Gen2 / Equine Intelligence Operating System**.

- Dados marcados como `SYN / DEMO`;
- sem autenticação, API, banco de dados, credenciais ou integração externa;
- não altera o HarasHub de produção;
- interações são locais no navegador e existem para validação de UX, arquitetura de informação e fluxos visuais.

## O que demonstrar

- Command Center por exceção;
- Cockpit Animal;
- reprodução, clínica, estoque, performance, financeiro e insights;
- Command Palette (`Ctrl/⌘+K`), tema claro/escuro, drawers e feedback de fluxo;
- responsividade desktop e mobile.

> Este repositório não é código de produção. A implementação no sistema real depende de aprovação explícita do visual e do fluxo.
